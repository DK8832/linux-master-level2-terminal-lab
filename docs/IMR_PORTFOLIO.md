# 리눅스마스터 2급 2차 대비 터미널 실습 기록

## 1. 문제와 목표

리눅스 명령은 이름과 옵션을 읽는 것만으로는 실제 파일 상태가 어떻게 바뀌는지 확인하기 어려웠다. 기존에 만든 프로그래밍기능사 웹 학습도구의 Linux 10문제는 개념 확인에는 도움이 되지만 실제 명령 입력과 출력 검증은 포함하지 않았다. 그래서 이 기록은 Linux만 분리해 Ubuntu 환경에서 직접 재현되는 터미널 실습으로 구성했다.

목표는 파일·권한·텍스트 처리·압축·프로세스·시스템 정보의 여섯 영역을 한 스크립트에서 안전하게 실행하고, 결과를 8개 체크로 검증하는 것이다.

## 2. 실습 설계

1. `pwd`, `id`, `uname`으로 기본 환경을 확인한다.
2. `mkdir`, `touch`, `cp`, `mv`, `find`로 파일을 만들고 이동 결과를 검사한다.
3. `chmod 755`, `stat`, `test -x`로 실행 권한을 수치와 동작으로 확인한다.
4. `grep`, `awk`, `sort -u`, `wc -l`을 파이프로 연결해 ERROR 2행과 고유 사용자 3명을 계산한다.
5. `tar -czf`, `tar -tzf`, `sha256sum`으로 압축 파일의 내용과 해시를 기록한다.
6. `ps`, `df`, `free`, `uptime`으로 프로세스·디스크·메모리·가동시간을 확인한다.

## 3. 안전성과 재현성

파일 실습은 `mktemp -d`로 만든 임시 폴더에서만 실행된다. 스크립트가 성공하거나 오류로 끝나도 `trap`이 임시 폴더를 정리한다. 사용자 계정 변경, 관리자 권한, 패키지 설치, 네트워크 설정은 포함하지 않았다.

GitHub Actions의 `ubuntu-latest`에서 `scripts/lab.sh`를 실행하고 로그를 `artifacts/latest-terminal-output.txt`로 남긴다. 이어서 Python 검증기가 로그의 8개 표식을 다시 확인한다. 따라서 화면 캡처만으로 결과를 주장하지 않고 스크립트·로그·워크플로를 함께 공개할 수 있다.

## 4. 실제 검증 기준

- 커널 문자열 `Linux`
- 이동한 파일 존재 및 이전 경로 부재
- 실행 스크립트 권한 `755`와 실행 가능 상태
- ERROR 행 수 2
- 고유 사용자 수 3
- tar.gz 파일 생성 및 SHA-256 출력
- 체크 수 `CHECKS_PASSED=8`
- 최종 상태 `LAB_STATUS=PASS`

## 5. 문제 해결

프로세스 목록을 `head`와 연결하면 `pipefail` 환경에서 앞 명령이 SIGPIPE로 종료될 수 있다. 전체 실습이 이 표시용 파이프 때문에 실패하지 않도록 해당 한 줄에만 `|| true`를 적용하고, 실제 평가 항목은 별도의 명시적인 `check` 함수로 검사했다.

파일 권한은 `ls -l`의 문자 모양만 보는 대신 `stat -c '%a'`로 755를 숫자로 추출하고 `test -x`로 실행 가능 상태를 한 번 더 검사했다. 텍스트 처리도 화면에 보이는 행을 세는 대신 결과 파일과 파이프의 행 수를 비교했다.

## 6. 배운 점

명령의 결과를 외우는 것보다 “명령 실행 → 상태 변화 → 다른 명령으로 검증”의 세 단계가 중요하다는 점을 배웠다. 또한 `set -euo pipefail`, 임시 폴더, `trap`을 사용하면 연습 스크립트도 실패를 숨기지 않고 사용자의 실제 파일을 건드리지 않게 설계할 수 있었다.

## 7. 한계와 다음 계획

현재 실습은 안전한 일반 사용자 명령에 집중해 계정·서비스·네트워크·패키지 관리처럼 관리자 권한이 필요한 영역은 다루지 않는다. 또한 이 실행 결과가 시험 합격이나 점수 향상을 의미하지 않는다. 다음에는 별도의 격리된 Linux 가상환경에서 서비스 상태 확인과 네트워크 진단을 읽기 전용 명령 중심으로 확장할 계획이다.

## 8. AI 활용 범위

실습 영역을 구조화하고 Bash 스크립트, Python 로그 검증기, GitHub Actions, 웹 노트, 문서 초안을 만드는 데 Codex를 활용했다. 명령이 실제로 성공했다고 AI가 추정하지 않도록 Ubuntu 워크플로의 실행 로그와 8개 검증 표식으로 확인하도록 설계했다.
